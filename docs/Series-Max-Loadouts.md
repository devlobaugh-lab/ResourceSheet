# Series Max Loadouts

The page will list 3 car setups for each series. Speed, Cornering, and Power Unit
The assumption is that the user has max level of all parts
The setups are then determined by the same logic as used for suggested setups on the car setups page. 

The listing will be somewhat consolidated
It will be a table like format. 
There will be a single col to left with series name that will row span 7 rows in that series group. 
There will then be 3 cols with header Speed, Cornering, Power Unit
Then 6 rows with the corresponding part for each setup. 

i.e.

|          | Speed | Cornering | Power Unit |
|-|-|-|-|
|  | brake | brake  | brake |
| Series 1 | engine | engine | engine|
| | ... | ... | ...|

|          | Speed | Cornering | Power Unit |
|-|-|-|-|
|  | brake | brake  | brake |
| Series 2 | engine | engine | engine|
| | ... | ... | ...|
